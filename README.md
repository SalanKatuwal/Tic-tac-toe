# Tic-tac-toe

A browser-based Tic-Tac-Toe game built with plain HTML, CSS and JavaScript (no build step).

- **vs Computer** — pick X or O and a difficulty: Easy (mostly random), Medium (wins and blocks, sometimes slips) or Hard (minimax, unbeatable).
- **vs Friend** — two players on one device, with custom names.

Scores are kept per match and the starting player alternates each round. Names and settings are remembered in the browser.

Open `index.html` in a browser, or serve the folder with any static server (e.g. `python3 -m http.server`).
